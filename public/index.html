Clock probing is available only for distributed runs. Hardware mode uses the first configured Ray worker as PTP grandmaster and makes the Ray head and remaining workers slaves. Clock Probe is bound to the exact NIC/PHC selected for each ptp4l sidecar. If the image has no ptp4l binary, supported Debian/Ubuntu amd64 or arm64 images install linuxptp with apt. Compare runs

Explains why run B is faster or slower than run A, per generated token, per decoder layer, per pipeline stage and per collective.

Pick a baseline (A) and a target (B), then analyze.

The engine reads every rank trace, splits each GPU's time into compute, communication hidden by compute, exposed communication, pipeline bubble and idle, and lines the runs up per generated token (the same basis as TPOT). The agent then writes a templated report; its conclusion appears here first.

  • Same GPU count, different layout (for example TP4 vs TP2×PP2): the plain difference B minus A.
  • Different GPU count (for example TP4 vs TP8): the loss against linear scaling.
